# DailyWorkout

live website link: https://aby1602.github.io/dailyworkout/

A personal interactive fitness tracker with muscle-based workout selection, guided circuits, workout logging, rest timers, weekly streaks and progress tracking.

## Features
- Interactive front/back muscle map
- Beginner, Intermediate and Expert workout levels
- Cardio warm-up, strength circuit and finisher
- Rest timers and set logging
- Weekly visit streak and workout streak
- Local browser history with localStorage
- Exercise demo links
- Responsive single-page interface
- Dumbbell favicon
